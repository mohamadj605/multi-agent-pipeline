## Background from memory (unverified)
- **June 2024:** Claude 3.5 Sonnet launched. It was positioned above Claude 3 Opus on many benchmarks at Sonnet-tier pricing. Artifacts also launched around this time.
- **October 2024:** An upgraded Claude 3.5 Sonnet (`claude-3-5-sonnet-20241022`) was released.
  - It improved coding results, including on SWE-bench Verified.
  - It introduced **computer use** in public beta, which lets Claude operate a computer by viewing the screen, moving the cursor and typing.
  - Claude 3.5 Haiku was announced at the same time.
- **Pricing:** Roughly $3 per million input tokens and $15 per million output tokens.
- **Successors:** Later Claude models, starting with Claude 3.7 Sonnet in early 2025, superseded 3.5 Sonnet. I believe Anthropic has deprecated or retired the 3.5 Sonnet models in its API, but I couldn't confirm the dates.
